# Data availability and controlled access

**Public historical archive (Dataset A).** `data/processed/dataset_escenarios_full_day.csv` is fixed in the original `carloskoo1/rural-radio-link-performance` repository at commit `d2cadaadd66da5184b2df63cc9e4fc6e34ee2ed8` (SHA-256 `ba575ced2bd2d626647e22c1da234e6f78fb9d073879120c24e10bfbe50cc39f`). Its 26,107 source rows include 11,707 rows in the five studied historical periods.

**Restricted 3×2 archive (Dataset B).** A frozen `weather_local_CU01_cierre.sqlite3` file (1,773,711,360 bytes; SHA-256 `2fdc7134b6a2b09da3c6370e36cd972a1759ed498eea1a2b04962186d41cccb7`) contains infrastructure and device identifiers. Neither the original nor a copy is publicly distributed through GitHub or the journal package. Requests for authorized access can be addressed to the corresponding author at **ckoo@unc.edu.pe**; provision depends on custody, security and applicable contributor agreements. **Availability is not guaranteed.**

**Public derivatives.** The frozen schedule, Tables S1–S4, figures, scripts and independent reconciliation audit may be examined without the private raw source. They support *derived-level* checks, not independent raw-data reproducibility of Dataset B.

**Future prospectives.** No observations from the separate prospective campaign are included.

**Citation and licensing.** Cite the fixed commit SHA for the files actually used. Public read access is not, by itself, a data-reuse license. Terms for third-party reuse have not yet been granted for the combined archive.
