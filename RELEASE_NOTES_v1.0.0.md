# Release v1.0.0

Versión reproducible asociada a la tesis.

Incluye procesamiento de telemetría, integración de ERA5-Land, análisis estadístico, índice de estabilidad y generación automatizada de productos.

Antes de publicar:
1. Reemplace la URL en `CITATION.cff`.
2. Verifique el nombre definitivo del archivo `.bat`.
3. Ejecute el pipeline desde una clonación limpia.
4. Confirme que no existan credenciales ni datos sensibles.
