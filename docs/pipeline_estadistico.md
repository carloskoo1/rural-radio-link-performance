# Pipeline estadístico

1. Shapiro–Wilk para normalidad.
2. Kruskal–Wallis para comparación global.
3. Épsilon cuadrado para tamaño del efecto.
4. Dunn con ajuste de Holm para comparaciones post hoc.
5. U de Mann–Whitney por escenario y franja.
6. Delta de Cliff para magnitud y dirección del efecto.
7. Spearman para precipitación y métricas técnicas.
8. Índice compuesto de estabilidad basado en DE del RSSI y CV de SNR, MCS y Throughput.

El índice es comparativo dentro del conjunto evaluado y no constituye una escala universal.
